Создание сайта мебельной фабрики «Enli»

Полный цикл работ по созданию многостраничного сайта
2025
Enli — крупная фабрика кухонь, работающая в промышленном масштабе и выпускающая сотни комплектов ежемесячно. Компания сочетает серийное производство с точной кастомизацией под заказ. Это современный производственный комплекс, рассчитанный на высокие объёмы и стабильное качество.

Главная

Главная страница реализована по принципу лендинга — содержит всю информацию для принятия решения оставить свои контакты или позвонить. Показана уникальность фабрики, её коллекции, проекты, преимущества мебели и удобство работы с компанией.

Страницы коллекций

Мебельные коллекции разделены на два типа, у каждой своя страница, которая содержит визуальную часть, стоимость, описание, есть возможность добавлять больше фото и списки с готовыми проектами.

Портфолио

Фабрика гарантирует идеальную сборку мебели, поэтому было важно показать как индивидуальные решения встают в интерьер. По каждому кейсу есть возможность добавить любое количество фото, схематические таблицы и описание.

Остальные страницы

На сайте есть страницы о производстве, информация для покупателей.
